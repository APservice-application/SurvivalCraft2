0. CORE VISION

สร้างเกม 2D Top-down Open World Survival RPG ที่ผู้เล่นสามารถใช้ชีวิต สำรวจ เอาตัวรอด สร้างบ้าน ปลูกพืช เก็บทรัพยากร Craft อุปกรณ์ ต่อสู้กับศัตรู ใช้เวทมนตร์ และพัฒนาโลกของตัวเองได้อย่างอิสระ

เกมต้องให้ความรู้สึกว่าเป็น "โลกที่มีชีวิต" ไม่ใช่แค่ฉากที่สร้างขึ้นมาเพื่อเดินผ่าน

ผู้เล่นสามารถเลือกวิธีเล่นของตัวเองได้ เช่น

- นักสำรวจ
- นักทำฟาร์ม
- นักสร้างบ้าน
- นักคราฟต์
- นักล่า
- นักรบ
- นักเวท
- นักเก็บทรัพยากร
- นักค้าขาย
- นักผจญภัย

ไม่มีเส้นทางการเล่นเพียงแบบเดียว

1. TECHNOLOGY PRINCIPLE

IMPORTANT:

เกมนี้จะไม่สร้าง Game Engine ขึ้นมาใหม่

ใช้ Game Engine ที่มีอยู่แล้วเป็น Runtime และ Rendering Foundation

ENGINE:

- Godot เป็นตัวเลือกหลัก
- Engine ต้องรองรับ 2D TileMap/TileSet
- Terrain / Autotiling
- Animation
- Physics
- Collision
- Navigation
- Audio
- Particles/VFX
- Scene system
- Resource system
- Input system
- Save/Load
- Scripting

AI มีหน้าที่สร้าง "เกมบน Engine"

AI ไม่มีหน้าที่สร้าง:

- Renderer ใหม่
- Physics Engine ใหม่
- Tile Engine ใหม่
- Scene Engine ใหม่
- Audio Engine ใหม่
- Animation Engine ใหม่
- Game Engine ใหม่

หาก Engine มีระบบอยู่แล้ว ต้องใช้ระบบของ Engine ก่อนเสมอ

48. DEFINITION OF DONE

Feature จะถือว่าเสร็จเมื่อ:

- Code ทำงาน
- เชื่อมกับระบบที่เกี่ยวข้อง
- UI มีจริง
- Error Handling มี
- Save/Load รองรับเมื่อจำเป็น
- Mobile Input รองรับเมื่อจำเป็น
- Performance ผ่านเกณฑ์
- ทดสอบแล้ว
- ไม่ทำระบบอื่นพัง

ห้ามถือว่าเสร็จเพียงเพราะ Compile ผ่าน
