# GAME DESIGN — SurvivalCraft2 (ฉบับย่อ)

> เอกสารเต็มคือ `docs/GAME_MASTER_ARCHITECTURE_TH.txt` (50 ข้อ)
> ไฟล์นี้อธิบายว่า "เกมนี้เล่นอย่างไร" ในแบบที่ผู้พัฒนาและ AI ใช้ตัดสินใจร่วมกันได้

## 1. Core Loop (Spec ข้อ 49)

```
สำรวจ → เก็บทรัพยากร → เอาตัวรอด → คราฟต์ → สร้างที่พัก → ปลูกพืช
   → ต่อสู้ → ค้นพบ → ได้ของใหม่ → อัปเกรด → สำรวจไกลขึ้น → เจอศัตรูแข็งขึ้น → พัฒนาตัว/ฐาน/โลก
```

ไม่มีเส้นทางตายตัว ผู้เล่นเลือกเป็นนักสำรวจ / นักทำฟาร์ม / นักสร้าง / นักคราฟต์ / นักล่า / นักรบ / นักเวท / นักค้าขาย ได้เอง

## 2. เป้าหมายผู้เล่น

| ระยะ | เป้าหมาย | สิ่งที่ต้องทำ |
|---|---|---|
| ต้นเกม (วันที่ 1–3) | อยู่รอดคืนแรก | เก็บไม้/หิน/เส้นใย → ทำขวานและอีเต้อ → ก่อกองไฟ → กิน/ดื่ม |
| กลางเกม (สัปดาห์แรก) | มีที่พักและอาหารมั่นคง | สร้างบ้าน + โต๊ะทำงาน + แปลงเพาะปลูก, ทำเครื่องมือหิน/เหล็ก, เรียนรู้เวทแรก |
| ปลายเกม | ขยายอิทธิพลในโลก | สำรวจ biome อันตราย (ป่าลึก/หิมะ/ซากปรักหักพัง/เขตเวทมนตร์), ล่าบอส, สะสมเวทและอุปกรณ์ระดับสูง |

## 3. ระบบชีวิต (สร้างเสร็จแล้วใน PHASE 1/9)

**HP · ความหิว · ความกระหาย · สตามินา · มานา · พลังงาน · อุณหภูมิร่างกาย · ความเปียก**

ระบบเชื่อมโยงกันเป็นลูกโซ่ เช่น:
```
ฝนตก → ตัวเปียก → อุณหภูมิร่างกายลด → กลางคืน+อากาศหนาว → Hypothermia → เสีย HP ต่อเนื่อง
```
สถานะปัจจุบันที่รองรับ: อดอยาก, ขาดน้ำ, หนาวเกิน, ร้อนเกิน, ตัวเปียก, หิว, กระหาย, อ่อนเพลีย (เพิ่ม พิษ/เลือดออก/ไฟไหม้/ป่วย ใน Phase 9–10)

## 4. โลกและ biome (สร้างเสร็จแล้วใน PHASE 2/3)

15 biome: ทะเลลึก · ทะเล · หาดทราย · ทุ่งหญ้า · ที่ราบ · ป่า · ป่าลึก · หนองน้ำ · ทะเลทราย · ภูเขา · หิมะ · ทะเลสาบ · แม่น้ำ · ซากปรักหักพัง · เขตเวทมนตร์ · ถ้ำ

แต่ละ biome กำหนด: พื้นผิว, พืช, ของประดับ, ทรัพยากร, สัตว์, ศัตรู, อุณหภูมิ, ความชื้น, เพลง, ambient, โครงสร้าง, เหตุการณ์ — ทั้งหมดอยู่ใน `shared/data/biomes.json`

**เวลา** 1 วัน = 16 นาทีจริง (มี dawn/morning/noon/evening/sunset/night/midnight และแสงเปลี่ยนจริง)
**อากาศ** 9 แบบ เปลี่ยนตามเวลาและ biome (ทะเลทรายไม่หิมะตก, หนองน้ำฝนบ่อย)

## 5. ทรัพยากรและไอเทม

| ประเภท | ตัวอย่าง |
|---|---|
| ทรัพยากร | ไม้ หิน แร่ เหล็ก ถ่านหิน ดินเหนียว เส้นใย สมุนไพร สมุนไพรเวท ผลึกเวท โบราณวัตถุ |
| เครื่องมือ | ขวานไม้/หิน, อีเต้อไม้/หิน, คบเพลิง |
| อาวุธ/เกราะ | ดาบเหล็ก, โล่ไม้, เกราะหนัง |
| อาหาร | เบอร์รี่, เห็ด, ข้าวสาลี, แครอท, ขนมปัง, ขวดน้ำ, น้ำแข็ง |
| ยา | ยาฟื้นพลัง, ยาเติมมานา |
| สร้าง | ชุดกองไฟ, ชุดโต๊ะทำงาน, กำแพงไม้, พื้นไม้, ประตูไม้ |
| เวท | คัมภีร์ไฟร์บอล (ปลดล็อกเวท) |

## 6. คราฟต์ (PHASE 6)

station: มือเปล่า → โต๊ะทำงาน → กองไฟ → เตาหลอม → ทั่งเหล็ก → โต๊ะเล่นแร่แปรธาตุ
สูตรคิดจาก `recipes.json` (วัตถุดิบ + station + เวลา) — 19 สูตรเริ่มต้น

## 7. ฟาร์ม (PHASE 8)

ไถดิน → หว่านเมล็ด → รดน้ำ → เติบโต 6 ระยะ (seed→sprout→young→growing→mature→harvestable) → เก็บเกี่ยว → คุณภาพผลผลิตขึ้นกับดิน/น้ำ/อุณหภูมิ/ฤดู
พืชเริ่มต้น: ข้าวสาลี (24 นาที), แครอท (16 นาที)

## 8. การต่อสู้และเวท (PHASE 10–12)

- ต่อสู้: ระยะประชิด (ดาบ/ขวาน/หอก/ค้อน/มีด), ระยะไกล (ธนู/หน้าไม้/โพรเจกไทล์เวท), มี critical/knockback/status/ธาตุ/คูลดาวน์/ใช้สตามินา
- เวท 10 ธาตุ: ไฟ น้ำ ดิน ลม น้ำแข็ง สายฟ้า ธรรมชาติ แสง มืด อาร์เคน
- ตัวอย่างเวท: ไฟร์บอล, Ice Spike, สายฟ้าฟาด, รักษา, โล่เวท, เทเลพอร์ต, อัญเชิญ, กำแพงไฟ, แช่แข็ง, คำสาปมืด
- พัฒนาเวท: เรียน → ใช้ → ได้ EXP → อัปเกรด → ปลดล็อกเวทขั้นสูง (มีสกิลทรี

## 9. ปุ่มควบคุม (mobile-first, Spec ข้อ 32)

| ปุ่ม | หน้าที่ |
|---|---|
| จอยสติ๊กลอย (ครึ่งซ้าย) | เดิน 8 ทิศ แตะตรงไหนก็ได้บนครึ่งซ้าย |
| โจมตี | โจมตี/เก็บของด้วยเครื่องมือที่ถือ |
| ใช้ | โต้ตอบ (เก็บพืช, เปิดหีบ, คุย NPC) |
| หลบ | กลิ้งหลบ ใช้สตามินา มีช่วงอมตะสั้น ๆ |
| วิ่ง | สลับโหมดวิ่ง (ใช้สตามินาต่อเนื่อง) |
| ✨ เวท | ร่ายเวทที่เลือก |
| 🎒 🗺 ⏸ | กระเป๋า / แผนที่ / หยุดพัก |
| หยิกสองนิ้ว | ซูมเข้า-ออก (เดสก์ท็อป: ล้อเมาส์) |
| คีย์บอร์ด (เดสก์ท็อป) | WASD/ลูกศร, Shift วิ่ง, Space หลบ, F ใช้, Q โจมตี, G เวท, Tab กระเป๋า, M แผนที่, Esc เมนู, F3 ดีบัก |
