# STYLE GUIDE (Spec ข้อ 9, 40)

> ทุก Asset และทุกโค้ดที่วาดภาพ **ต้อง** ยึดเอกสารนี้
> ห้ามนำของหลายสไตล์มาปะปนกันโดยไม่ปรับให้เข้ากัน (Spec ข้อ 40)

## 1. มุมมองและขนาด

| หัวข้อ | ค่า |
|---|---|
| มุมมอง | Top-down (มองจากด้านบนเฉียงเล็กน้อย) |
| Tile ต้นฉบับ | 16 × 16 px |
| Tile บนจอ | 34 px (@zoom ปกติ) → ตัวละครสูง ~1.25 tile |
| สไปรต์เรนเดอร์ | 16 px × 2 = 32 px (pixel-perfect, ไม่ใช้ smoothing) |
| ตัวละครผู้เล่น | กว้าง 0.6 tile สูง 1.25 tile, รัศมีชน 0.30 tile |
| ต้นไม้ | 2 × 2 tile (สูง ~2.5 tile รวมเรือนยอด) |
| ช่วง zoom ที่อนุญาต | 20–58 px/tile (ต่ำ/กลาง/สูง ต่างกันเล็กน้อย) |

## 3. กฎคุณภาพภาพ (ห้ามละเมิด)

1. **ห้ามใช้สีพื้นเรียบ** — ทุก tile ต้องมี texture: sub-block เฉดสี, เกรนพิกเซล, และ feature (หญ้า/กรวด/รอยแตก/ระลอกน้ำ)
2. ทุก tile ต้องมี **variant อย่างน้อย 8 แบบ** เพื่อไม่ให้เห็นลายซ้ำเป็นตาราง
3. รอยต่อระหว่างพื้นต่างชนิดต้องมี **transition blending** (เกลี่ยเม็ดสีที่ขอบ 30% ของ tile)
4. ของบนพื้น (prop) ทุกชิ้นต้องมี **เงา** และ **ไฮไลต์แสง**
5. ต้องมี **decoration ธรรมชาติ** (หญ้า ดอกไม้ เห็ด กรวด) กระจายแบบ cluster/clearing
6. กลางคืนต้องมี **แสงและเงา** (คบเพลิง/กองไฟ/ผลึก) ไม่ใช่แค่ทำจอมืด
7. ห้ามใช้ `imageSmoothing` (ต้อง pixel-perfect)

## 4. ลำดับชั้นภาพ (Visual Hierarchy)

| ชั้น | ลำดับการวาด | หมายเหตุ |
|---|---|---|
| 1. Terrain | ล่างสุด | tile + transition |
| 2. Ground deco | ถัดมา | ดอกไม้/เห็ด/หญ้า (ไม่บังตัวละคร) |
| 3. Entities | เรียงตามแกน Y | ของที่ "อยู่หลัง" วาดก่อน |
| 4. Player | ตามแกน Y | ความสูง 1.25 tile |
| 5. Light & Weather | ทับ | คำนวณจากเวลา + อากาศ |
| 6. UI | บนสุด | HUD, ปุ่ม, panel |

## 5. UI (Spec ข้อ 33)

- อ่านง่ายบนมือถือกลางแจ้ง: contrast สูง, ตัวอักษร ≥ 12.5 px, ปุ่ม ≥ 44 px
- HUD อยู่ขอบจอ ไม่บังกลางจอ (กลางจอ = พื้นที่เล่น)
- ปุ่มขวาล่าง = แอ็กชัน, จอยซ้ายลอย (แตะตรงไหนก็ได้)
- ใช้ภาษาไทยทั้งหมดใน UI (ผู้เล่นหลักเป็นคนไทย)
- Panel เปิดจากล่างจอบนมือถือ / กลางจอบนเดสก์ท็อป

## 6. แอนิเมชัน

| สิ่ง | รายละเอียด |
|---|---|
| เดิน | ขาแกว่ง ±16% ของความสูงตัว, คาบ ~7.5 cycle/วิ |
| วิ่ง | เร็วขึ้นเป็น ~11 cycle/วิ + เอนตัวเล็กน้อย |
| ยืนนิ่ง | หายใจเบา ๆ (bob 0.7 px) |
| กลิ้งหลบ (dodge) | 0.34 วิ + โปร่งแสงเป็นช่วง, อมตะ 0.25 วิ |
| น้ำ | 4 เฟรม วน ~0.42 วิ/เฟรม |
| ต้นไม้ | แกว่งเบา ๆ ตามลม (Phase 3+) |

## 7. เสียง (Spec ข้อ 29)

- BGM แยกตาม biome (plains/forest/cave/snow/desert/magic) + เปลี่ยนตอนกลางคืน
- Ambient แยกตาม biome (นก, คลื่น, แมลง, ลม, หยดน้ำ)
- Footstep ตามพื้นผิว: grass, dirt, stone, sand, snow, water
- VFX เสียงต้องสั้น (< 300 ms) และไม่บังเสียงสำคัญ
